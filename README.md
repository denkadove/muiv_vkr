# Преддипломная практика muiv

Отчетный проект по преддипломной практике

## Расширения админ-панели

Админка (`app/modules/admin`) — хост. Разделы каталога подключаются к ней как
расширения через реестр `app/registry.py`:

- `AdminExtension.blueprint_path` — блюпринт расширения (`модуль:имя`), его модели
  импортируются из `AdminExtension.models` до первого запроса;
- `AdminExtension.menu` — пункты сайдбара (секция, заголовок, endpoint и
  endpoint'ы для подсветки);
- `AdminExtension.breadcrumbs` — описание разделов для хлебных крошек.

Общие шаблоны лежат в `app/templates/structure/` (`admin_base.html`,
`admin_sidebar.html`, `pagination.html`). Шаблоны расширения — в его собственном
`templates/<ключ>/`, чтобы не было коллизий имён.

Чтобы добавить расширение, создайте блюпринт и добавьте один `AdminExtension`
в `ADMIN_EXTENSIONS`. Правки в сайдбаре и breadcrumbs не нужны.

## Импорт данных из Ozon

Кнопка «Обновить из Ozon» на вкладке «Цены» запрашивает
`/v5/product/info/prices` и сохраняет цены, все виды комиссий, логистику,
эквайринг, индексы цен и акции.

- В карточке магазина «Озон» заполните `Api-ключ` и `Client-Id`.
- В форме товара у каждой связи с магазином укажите `offer_id` — артикул
  товара в Ozon. Без него товар пропускается.
- Полный ответ API хранится в `ProductMarketplace.ozon_data` (JSON), а проценты
  комиссий, цена и дата обновления — в отдельных колонках. Значение `15`
  из API сохраняется как `0.15` (15 %).
- При ошибке API старые данные не затираются, а причина пишется в `ozon_error`.

Клиент API лежит в `app/modules/catalog/integrations/ozon.py`, сервис импорта —
в `app/modules/catalog/ozon_import.py`. Новые маркетплейсы подключаются записью
в `CLIENTS` в `app/modules/catalog/integrations/__init__.py`.

После обновления схемы примените миграции: `flask db upgrade`.
